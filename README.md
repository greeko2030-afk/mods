# Minecraft 1.21–1.21.11 Fabric Performance Mods

This repository contains Minecraft optimization mods for Fabric loader on Minecraft 1.21–1.21.11.

Use the official Modrinth pages below and download the version that matches your Minecraft version and loader.

## Required / Core
- Fabric Loader: https://fabricmc.net/

## Performance Mods
- Sodium: https://modrinth.com/mod/sodium
- Lithium: https://modrinth.com/mod/lithium
- FastQuit: https://modrinth.com/mod/fastquit
- ImmediatelyFast: https://modrinth.com/mod/immediatelyfast
- Krypton: https://modrinth.com/mod/krypton
- Connectivity: https://modrinth.com/mod/connectivity
- ModernFix: https://modrinth.com/mod/modernfix

## Notes
- Always choose the version that matches your Minecraft version (1.21.x / 1.21.11) and Fabric loader.
- If a mod has multiple versions, prefer the latest stable build for your target version.
- Not every mod is guaranteed to be compatible with every other mod; check the mod pages before installing.

## Example naming pattern for downloaded files
- sodium-fabric-mc1.21.11-<version>.jar
- lithium-fabric-mc1.21.11-<version>.jar
- fastquit-fabric-mc1.21.11-<version>.jar
- immediatelyfast-fabric-mc1.21.11-<version>.jar
- krypton-fabric-mc1.21.11-<version>.jar
- connectivity-fabric-mc1.21.11-<version>.jar
- modernfix-fabric-mc1.21.11-<version>.jar

This repository is intended to hold the actual mod jar files. The links above lead to the official source pages for the mod downloads. If you want the binary .jar files uploaded directly here, add the actual download URLs or uploaded jar files for each mod.
